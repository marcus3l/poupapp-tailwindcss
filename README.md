# PoupApp — painel financeiro com Tailwind CSS

Painel de finanças pessoais com visão de contas, orçamento diário, metas de economia e transações. Esta implementação do desafio estiliza os componentes com Tailwind CSS.

## Funcionalidades

- Resumo de contas e saldos
- Indicador de orçamento diário e progresso de economia
- Lista de transações e busca
- Componentes reutilizáveis com utilitários Tailwind

## Tecnologias

React, JavaScript, Vite, Tailwind CSS e PostCSS.

## Como executar

```bash
npm install
npm run dev
```

O Vite informa no terminal o endereço local da aplicação. Para criar a build de produção, execute `npm run build`.

## Contexto

Versão do desafio PoupApp dedicada à prática de estilização com Tailwind CSS.
